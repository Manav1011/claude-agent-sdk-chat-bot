❯ Build a highly polished, production-quality **SGLang Model Performance &      
  Monitoring Dashboard** as a single-page frontend.                             
                                                                                
  This is a **frontend capability benchmark**. The goal is to evaluate how well 
  you can transform real model-serving telemetry into a beautiful, responsive,  
  interactive monitoring interface.                                             
                                                                                
  ## IMPORTANT: NO BACKEND / NO API                                             
                                                                                
  There is **no backend API available**.                                        
                                                                                
  The dashboard must be completely self-contained and operate entirely on a     
  **static dataset embedded inside the HTML/JavaScript**.                       
                                                                                
  Do NOT:                                                                       
                                                                                
  * Make API requests.                                                          
  * Try to connect to Prometheus.                                               
  * Try to connect to SGLang.                                                   
  * Require a backend.                                                          
  * Require environment variables.                                              
  * Require a database.                                                         
  * Simulate an API server.                                                     
                                                                                
  Instead:                                                                      
                                                                                
  * Embed the provided telemetry data directly inside the JavaScript.           
  * Treat that data as if it were the current state of the SGLang server.       
  * Build all charts, statistics, tables, filters, modals, and visualizations   
  from this local dataset.                                                      
  * User interactions should modify the frontend state locally.                 
  * Actions such as restart, stop, deployment, etc. should be simulated         
  entirely in the browser.                                                      
  * Make it obvious in the UI that this is a **static/demo telemetry            
  snapshot**, for example with a small "Static Snapshot" indicator.             
                                                                                
  The dashboard should still feel like a real production monitoring             
  application.                                                                  
                                                                                
  ## Technical Requirements                                                     
                                                                                
  * The entire application must run from a single `index.html`.                 
  * Put all CSS inside `<style>`.                                               
  * Put all JavaScript inside `<script>`.                                       
  * The page must work by simply opening `index.html`.                          
  * No npm.                                                                     
  * No React/Vue/Angular.                                                       
  * No build process.                                                           
  * No server required.                                                         
  * External CDN libraries are allowed if useful.                               
  * Prefer vanilla JavaScript where practical.                                  
  * No placeholder functionality.                                               
  * No `TODO` sections.                                                         
  * No "coming soon" interactions.                                              
  * Everything visible should work.
